# 解释可信度与阅读路径整改（2026-10-29）

来源：外部逐页走查（6 步）+ 构造数据复现。本文件逐条记录**已修 / 未修**与证据位置，
避免「说了改了」与「代码里到底是什么」再次脱节。

## P0 一：同窗证据（已修）

**问题**：摘要解释的是 10-28→10-29 黄金下跌 0.66%，展开「实际收益率」给出的却是
10-26→10-27「实际收益率 −2bp、黄金 +1.07%」。历史关系被当成当期证据。

**根因**：事实用目标资产最新窗口，机制各自 `alignCommon` 取自己最新的共同日期。

**修法**：
- `alignment.js` 新增 `changeBetween(series, start, end)`（按指定日期算，不做「取最后 N」）。
- `explanations.service.js` 先算目标窗口 `anchor`，同一 `anchor` 传给 `buildFacts` 与
  `evaluateMechanism`。
- `evidence.js`：驱动覆盖不了 anchor 时返回 `status=untested` + `reasons=[OUT_OF_WINDOW]`，
  证据降级为 `role=background` 并注明「不在本次窗口内」。
- `compose.js`：驱动事实增加 `alignedToTarget`（true/false/null），界面据此写「历史背景」。
- `CALCULATION_VERSION` 抬到 `calc-v3`（不改版本会让旧快照按指纹命中、继续错下去）。

**实测**（冷启动、空数据目录）：
```
窗口 2026-10-28 → 2026-10-29
untested      M-GOLD-REAL-YIELD   2026-10-28 → 2026-10-29 OUT_OF_WINDOW
fact dfii10   2026-10-26 → 2026-10-27 aligned false
fact us10y    2026-10-28 → 2026-10-29 aligned true
```

## P0 二：内外金对照的窗口对齐（已修）

**问题**：三条序列各切各的，只对齐末端。国内金缺一天时，起点比国际金早一天 →
「两天溢价都为零」也会算出一个非零的溢价变化。

**修法**：`comparison.service.js` 新增 `commonWindow(rowsList, points)` —— 先在**日期交集**
上定起止，再按该日期取价（缺端点返回 null，不做「就近取」）；交集不足两点直接
`status=unknown`、不给分解。

**测试**：`tests/comparison-service.test.js` 增 4 条（交集取窗口、交集不足、无交集、
缺端点），并加 1 条端到端：缺一天 + 溢价恒为 0 → 溢价变化 ≈ 0 且 `residualPct` ≈ 0。

## P0 三：机制适用条件（已修，第 85 轮）

- 名义收益率上升、实际收益率下降时，名义利率渠道仍可能判为「观测一致」——
  需要在渠道评估里检查**中间变量方向**（如 `t10yie` 与 `dfii10` 的关系）。
- 「原油需求下降」的新闻可能被归入需求类，再支持「需求增强」——
  `shock.js` 的事件方向分类需要与机制方向对齐（`demandDown` 不能支持 `sign>0` 的需求渠道）。
- 现状：已按 `requires` + 方向与事件前提校验，见下。

**已修（第 85 轮）**：

1. **事件前提**（`mechanisms.js` 的 `eventPremise` + `evidence.js`）：
   `M-GOLD-OIL-POLICY` 声明 `{ shockType:'supply', direction:'decrease' }`。
   「需求增加」的报道不再进入这条渠道 → `untested / SHOCK_DIRECTION_MISMATCH`；
   报道方向没写清 → `untested / SHOCK_DIRECTION_UNKNOWN`（不猜）。
2. **方向分类**（`shock.js`）：从「只分供给/需求」扩到「供给/需求 × 增加/减少」，
   双向表述或词本身不带方向（如单独出现「开工率」）→ `direction: null`。
3. **名义渠道前提**（`NEEDS_REAL_YIELD_CONFIRMATION`）：名义上行而实际下行时
   判 `untested`——那条渠道讲的是真实回报上升，前提不成立
   （与机制自己的 exclusions 一致）。
   **不要求 t10yie 与 dfii10 同向**：名义上行 + 实际下行（通胀补偿涨更多）是正常组合。
4. **算术一致性只作护栏**：`|名义 − 实际 − 通胀补偿| > 5bp` → `untested / RATE_IDENTITY_MISMATCH`。
   代码里写明：T10YIE 由名义与实际算出，同源自洽是应该的，**不能当独立证据、
   也不提升结论等级**（有专门的用例钉住「自洽但没有价格支持时仍 not_supported」）。

## P0 四：修订引用（部分修）

已修：
- 指纹现在覆盖**窗口起止日期及其值**（以前只有「最后一格」），起点被修订会让旧快照失效；
- 指纹纳入观测的 `revision`（同 id 不同修订 = 不同事实）。

已修（第 85 轮）：
- `observationIdOf(id, date, revision)`：修订号 > 1 时输出 `资产@日期#rN`
  （r1 保持人类可读的原样），证据引用带上观测的修订号。

未修：
- 载入层还没有把 `revision` 挂到 `observations` 上，所以线上 id 目前仍是 `资产@日期`
  形式；一旦采集侧提供修订号，引用会自动带上 `#rN`。这条要在采集/存储接线时补。
  需要 `observationIdOf(id, date, revision)` 与库表 `logical_key/revision` 对齐，
  并迁移已存快照里的引用（或按 `logical_key` 反查当前修订）。

4. 事件中心「今天重点」（**已修，第 86 轮**）：
   · 时区：`releaseAt` 是 UTC ISO，界面切字符 → 13:30，而日历显示 21:30。
     现在服务端给 `releaseLocal`（北京时间），文案显式写「（北京时间）」；
   · 语言：今天重点混进德语/韩语/意大利语标题。现在同等级下优先中文报道
     （非中文不剔除，靠后并标「原文（非中文）」）；不机器翻译 —— 翻了就是我编的内容；
   · 内部代码：`why` 里曾直接印 `关联可解释标的（us10y）`，改成「关联到美国 10 年期国债收益率」；
   · 重复序号：`<ol>` 自带编号 + `.tf-idx` 叠成「1 1」，改用 `<ul>`；
   · 样式：`.tf-*` 一条规则都没有（呈现为普通文本列表），补齐并加静态守卫。
5. 详情页并发 + 空括号（**已修，第 88 轮**）：
   · 并发：只比 `seq` 不够 —— 切资产时 seq 归零，「黄金第 1 次」与「原油第 1 次」
     相等，慢响应能通过校验。加 `epoch`（每次重建状态递增），三道校验
     「同一代 + 同资产 + 同序号」缺一不可；history / replay 同样带 epoch。
   · 空括号：幅度缺失时只写「为何走弱」，不写「为何走弱（）」。
6. 内外金对照（**已修，第 87 轮**）：
   · 位置：入口原来在走势/分时/指标之后，提到**解释卡之后**；
   · 标题：副标题写真实起止日期（`近 5 日 · 2026-10-17 → 2026-10-23`），
     缓存过期时明说「日线缓存已过期（不是实时价）」；服务端新增 `windowRange`；
   · 样式：`.cmp-*` 补齐（三项分解的 grid、残差说明、窄屏收起第三列）。
